## 登记规则

- `已核对`：证据文件存在，内容已人工核对，能够直接支撑该表述。
- `进行中`：正在生成或整理，但不足以支撑完成时态的论文结论。
- `待补`：只有计划或口头描述，正文中不能写成既成事实。
- 修改公式、数据、算法或 API 后，应新增一条记录或更新风险说明，并在 `CHANGELOG.md` 记录影响。
