# 论文文献检索库

本目录与本机 Zotero 配合，用于分类和追踪与“双轴桨叶式混合机智能设计”学位论文有关的文献。Zotero 管理文献元数据、原文和批注；本目录管理文献卡片、可用摘录、论文位置与证据状态。目录结构与 `docs/outline.md` 对应。

## 一、核心规则

1. 每篇文献分配唯一编号，格式为 `LIT-0001`、`LIT-0002`，编号一经使用不得复用。
2. 原文及其批注由 Zotero 保存；仓库章节文件夹只保存同编号 Markdown 文献卡片。
3. Zotero 条目的“其他（Extra）”字段记录 `LIT-ID`、主要章节、次要章节和卡片相对路径。
4. 一篇文献可加入多个 Zotero 集合，但只能有一个条目和一份附件；其他章节通过集合、卡片和 `章节文献地图.md` 建立交叉引用。
5. 每条摘录必须记录页码、图表号或章节位置；无法定位的内容不能作为正式论文证据。
6. “原文摘录”“自己的转述”“拟写入论文的句子”必须分开记录，严禁混写。
7. 师兄的双螺杆膨化机论文只能记录写作结构启发，不得作为本课题公式、数据、模型或结论的来源。
8. 原始 PDF、CAJ 和下载附件保存在 Zotero 数据目录，不提交 Git；文献卡片、索引和引用元数据可以进入版本管理。

## 二、目录说明

2026-09-16学位论文写作参考批次按用户明确要求，在`01-绪论/90-学位论文写作参考/原文/`保留实际下载文件的本地副本，并关联Zotero附件。此为本批本地原文存储约定；当前5篇条目已入Zotero，原文尚未下载。

- `00-待整理/`：暂存尚未建立 Zotero 条目或未完成归类的卡片，不作为长期原文存储区。
- `01-绪论/` 至 `06-总结与展望/`：按论文大纲存放对应 Markdown 文献卡片。
- `90-跨章节方法与标准/`：同时服务多个章节的通用方法、标准、软件官方文档和统计规范。
- `91-引用与导出/`：保存 BibTeX、RIS 导入队列和文献管理软件交换文件。
- `99-模板/`：文献卡片与章节索引模板。
- `文献总表.md`：全库唯一总账，登记每篇文献的编号、位置、阅读和核验状态。
- `章节文献地图.md`：从论文段落反查可用文献及仍缺什么证据。
- `阅读日志.md`：按日期记录阅读、摘录、核验和废弃原因。
- `目录树.md`：显示与论文大纲逐级对应的完整文件夹结构。
- `Zotero同步说明.md`：规定 Zotero 集合、标签、Extra 字段、批注和引用导出方式。

## 三、新文献入库流程

1. 将论文保存到 Zotero 顶层集合下的“00 待整理”。
2. 在 Zotero 中查重，并核验题名、作者、年份、期刊、DOI/学位授予单位等元数据。
3. 在 `文献总表.md` 分配下一个 `LIT` 编号；优先以 DOI 去重，无 DOI 时使用“规范化题名 + 第一作者”。
4. 在 Zotero 的 Extra 字段写入 `LIT-ID` 和论文位置，再将条目加入对应章节集合。
5. 在仓库对应章节文件夹复制 `99-模板/文献卡片模板.md`，文件名以 `LIT-ID` 开头。
6. 在 Zotero 中阅读和批注；准备写入论文的摘录再转写至文献卡片，并分配 `EX-xxxx` 编号。
7. 将可用摘录登记到对应章节的 `_本章文献索引.md`，并在 `章节文献地图.md` 更新证据状态。
8. 正文真正引用后，填写正文定位和引用编号；定稿前再次核验元数据、全文和页码。

## 四、状态词表

阅读状态只使用：`待读`、`粗读`、`精读`、`已摘录`、`已用于正文`、`不采用`。

核验状态只使用：`未核验`、`元数据已核验`、`全文已核验`、`引用已复核`。

证据状态只使用：`缺失`、`候选`、`可用`、`已引用`、`不适用`。

## 五、摘录是否可写入论文的最低条件

- 原文文件可访问；
- 作者、题名、年份和来源已核验；
- 摘录有准确页码或图表号；
- 转述没有扩大原作者结论；
- 研究对象和工况与本课题的可迁移边界已说明；
- 拟插入章节及该句在段落中的作用明确；
- 论文正文中的引用编号能回指该文献卡片。

未满足上述条件的材料可以保留为阅读笔记，但不得作为已核验论文证据。
