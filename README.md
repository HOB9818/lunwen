# 双轴桨叶式混合机智能设计硕士论文

本仓库用于管理硕士论文的章节正文、章节目标、研究证据、写作任务和修改历史。正文按章节拆分为 Markdown 文件，章节标题和内容都可以独立修改；Git 提交记录保留每一次变更，`CHANGELOG.md` 记录影响论文结构或结论的重要修改。

> 仓库默认应保持为 **private**。师兄论文仅作为结构参考，不上传原文，也不能作为本课题数据、公式、结论或实现细节的证据。

## 当前研究主线

1. 分析双轴桨叶式混合机的混合过程、结构参数和性能指标。
2. 建立混合均匀度、功率与产量模型，并完成独立验证。
3. 完成参数寻优和近优方案综合评价。
4. 基于 SolidWorks 方程式、外部参数文件和宏开发参数化建模窗口。
5. 将知识匹配、性能计算、参数寻优、综合评价和模型生成整合为智能设计系统，并用真实案例验证。

## 一次标准修改

```powershell
git switch -c codex/chapter-5-macro-ui
# 修改章节、证据登记和进度表
git add chapters docs CHANGELOG.md
git commit -m "写作: 补充5.3.5参数化模型生成与预览"
git push -u origin codex/chapter-5-macro-ui
```

小范围文字修订可以直接提交到 `main`；涉及章节重构、方法替换或结论变化时，建议使用分支和 Pull Request，便于比较修改前后差异。
